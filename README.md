## ✦ Key Features

- **Performance-Engineered Architecture**: Granular route and vendor code-splitting (`vendor-three`, `vendor-gsap`, `vendor-motion`), WebP optimized imagery (reduced assets footprint by 80%), and `<Suspense>` lazy-loading.
- **Permanent High-Performance Dark Aesthetic**: Tailored deep-space palette (`#0C0D11`, `#0D0E12`, `#14161E`) with high-contrast cobalt (`#2B59FF`) and acid-lime (`#7CE028`) accents meeting WCAG AA contrast standards.
- **8 Flagship Systems & Repositories**: Grounded engineering portfolio with detailed modal breakdowns, technical architectures, tech tags, and direct GitHub links.
- **Academic & Industry Journey**: Verified timeline featuring the **Infosys Springboard** AI/ML internship, **Hostel Hackathon** honors, **JudahCode Tech** software internship, and **STEM Innovators Expo** credentials.
- **Motion & Accessibility**: Lenis smooth scrolling that respects `prefers-reduced-motion`, Three.js canvases with IntersectionObserver and battery-saving rAF pausing, and full screen-reader a11y.
- **Contact & Inquiry Suite**: Integrated Web3Forms contact form with client-side validation, honeypot spam protection, accessible copy feedback, and automatic fallback to mailto.

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/Arjunan-lab/Portfolio.git

# Navigate into the project directory
cd Portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The application will be live at `http://localhost:5173`.

---

## 📦 Production Build

```bash
# Compile and bundle for production
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deploy to Vercel

This repository is pre-configured with `vercel.json` for one-click deployment:
1. Import the repository on [Vercel](https://vercel.com/new).
2. Framework Preset: **Vite**.
3. Build Command: `npm run build`.
4. Output Directory: `dist`.
5. Click **Deploy**.
