## ✦ Key Features

- **Permanent High-Performance Dark Aesthetic**: Tailored deep-space slate (`#0C0D11`, `#0D0E12`, `#14161E`) with vibrant cobalt and acid-lime accents.
- **9 Flagship Projects Gallery**: Structured grid layout with interactive modal breakdowns, technical architectures, tech tags, and direct GitHub links.
- **Interactive Competencies & Capabilities**: Hover-to-elaborate competency matrix covering Programming, Distributed Systems, ML Inference, and Low-Latency Design.
- **Academic & Industry Journey**: Verified timeline featuring the **Samsung Innovation Campus** certification, **Hostel Hackathon** awards, and **STEM Innovators Expo** credentials.
- **Zero-Latency Smooth Motion**: Powered by Lenis smooth scrolling, Three.js 3D kinetic wireframes, and Framer Motion.
- **Direct Collaboration Suite**: One-click email copying, phone connect, and direct inquiry messaging.

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/Arjunan-lab/Portfolio.git

# Navigate into the project directory
cd Portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The application will be live at `http://localhost:5173`.

---

## 📦 Production Build

```bash
# Compile and bundle for production
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deploy to Vercel

This repository is pre-configured with `vercel.json` for one-click deployment:
1. Import the repository on [Vercel](https://vercel.com/new).
2. Framework Preset: **Vite**.
3. Build Command: `npm run build`.
4. Output Directory: `dist`.
5. Click **Deploy**.
